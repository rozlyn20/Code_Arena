## 📖 About

CodeArena is a collaborative coding platform where developers can create or join coding rooms and solve problems together in real time.

Whether you're preparing for technical interviews, conducting mock interviews, teaching programming, or pair programming with friends, CodeArena provides a smooth collaborative coding experience.

---

## ✨ Features

* 🎯 Create and join coding rooms
* 👥 Real-time collaborative code editing
* 💻 Monaco Editor integration
* 🌐 Multi-language support
* ⚡ Socket.IO powered live collaboration
* 📋 One-click room ID sharing
* 👤 Live participant list
* 🎨 Modern responsive UI
* 🔔 Toast notifications
* 🌙 Dark theme

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/codearena.git
```

```bash
cd codearena
```

### Install dependencies

Frontend

```bash
npm install
```

Backend

```bash
npm install
```

### Start the development servers

Frontend

```bash
npm run dev
```

Backend

```bash
npm run server
```
